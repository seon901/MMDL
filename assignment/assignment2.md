# Final project: Qwen3-VL-4B performance improvement

최종 과제 모델은 LoRA를 병합한 단일 R20이다. 앙상블은 추가 탐구로 구분한다.

| 평가 | 순정 | R20 | 차이 |
|---|---:|---:|---:|
| MMMU Test 10,500개 | 50.60% | 51.70% | +1.10%p |
| 고정 취약 8과목 3,112개 | 34.99% | 37.72% | +2.73%p |
| MMMU-Pro standard 1,730개 | 36.07% | 37.11% | +1.04%p |
| MMMU-Pro vision 1,730개 | 28.67% | 29.71% | +1.04%p |

위 수치는 저장된 고정 평가 코드의 결과이며 공식 리더보드 점수가 아니다.
전체 Test에서 선택지 그림을 입력에 넣지 못하는 366문항을 확인했다.
그중 271문항은 전달 이미지가 0개다. 수정 후 재평가 결과는 이 묶음에 없다.
두 모델에 같은 파이프라인을 적용했어도 완전한 이미지 입력의 성능으로 해석할 수 없다.

## 방법과 분석

언어 attention의 q/k/v/o에 rank 8, alpha 16의 LoRA를 적용했다.
Vision과 merger를 동결하고, 이미지 3,200개와 텍스트 Replay 800개를
학습률 2e-4, 500단계, seed 42로 학습했다.
데이터 비율, 학습률, rank, Replay, 풀이형, 어려운 문항 보강을 비교했다.

전체 Test는 회복 1,239개, 퇴보 1,124개로 정답이 115개 늘었다.
30과목 중 14상승, 5유지, 11하락이었다. 개별 영역의 퇴보가 남아 있다.
단일 시드, 반복 Validation 탐색, 기평가 Test ID 2,053개 포함과 입력 누락이 한계다.

추가 탐구의 5모델 투표는 Validation에서 R20 대비 정답 14개가 늘었지만,
모델 로딩을 제외한 평가 시간 합은 28.4분에서 104.0분으로 증가했다.
이 결과는 최종 단일 모델 성과와 구분한다.

실행과 데이터 준비 안내는 저장소 루트 README.md를 따른다.
